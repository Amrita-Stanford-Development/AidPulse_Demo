AidPulse — Retrieval Reviewer Demo

A reduced, standalone companion to the manuscript "AidPulse: LLM-Augmented Patient Similarity Search for Clinical Decision Support" — retrieval only, no LLM step.

What this is (and isn't) — read before using

This demo exists to answer one specific reviewer question: can you actually run the trained retrieval models on an input and see the output? It reproduces only the encode → nearest-neighbor step of the pipeline described in the manuscript. It is not the AidPulse application (patent-pending, excluded here the same way it's excluded from the reviewer package) and it does not include the LLM clinical-reasoning step.

  • Cardiology — the real trained model and its real 10,254-patient corpus (public Kaggle Cardiovascular Disease dataset), the same artifact already shared in the reviewer package. You can type in any hypothetical patient.
  • Ophthalmology (AIMS Kochi) — real embeddings from the real trained model for the actual 236-patient private cohort behind manuscript Table 5. No model weights (encoder or decoder) are included, and no raw clinical values are included — only a coarse age-decade, gender, and CAD-type label per case. Patient IDs shown are shuffled demo indices with no relation to the source records. Because the encoder isn't shipped, you can only pick among the 236 real (anonymized) cases as your query, not type a new hypothetical one.

Submit a hypothetical patient

Runs the real trained Cardiology encoder in your browser (no server) and retrieves nearest neighbors from the real 10,254-patient corpus by cosine similarity.

Pick one of the 236 real (anonymized) cases

Retrieves nearest neighbors for the selected case from the real trained embeddings, by cosine similarity — the same mechanism manuscript Table 5 is built on.

Note on reading results: this cohort is imbalanced (175 Chronic Stable Angina vs. 26 ACS vs. 35 Asymptomatic). Chronic Stable Angina cases retrieve well (~74% same-label neighbors); ACS and Asymptomatic cases retrieve poorly (~11–13%) because the corpus barely contains anything else to match them to. That's the real, already-published Purity@5 behavior of this model (see baseline_comparison_metadata.csv), not a demo bug — pick an ACS or Asymptomatic case to see it.

Source and data-export script: see scripts/export_demo_data.py in this repository for exactly how each file here was derived from the manuscript's models. Nothing in this repository can reconstruct a real AIMS patient record.
